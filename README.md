# sealquery

Seal validation gates for query inputs before they hit prod.

**Site:** https://theworker02.github.io/sealquery/

## Install / run

```bash
git clone https://github.com/theworker02/sealquery.git
cd sealquery
node src/cli.js
node --test
```
